What is Istio?

Istio estende seu cluster Kubernetes criando uma malha de serviços programável. Trabalhando com workloads no Kubernetes ou tradicionais, Istio adiciona consistência, gerenciamento de tráfego universal, telemetria e segurança para os sistemas mais complexos.

Escolha as funcionalidades que você quer e o Istio cria toda infraestrutura de proxies necessária. Use o túnel de segurança zero na camada de rede, para performance e segurança, ou adicione instâncias de Envoy para funcionalidades utilizando camada de aplicação.

Istio Providers

Istio is supported and implemented by an ecosystem of leading providers and consultants. You can install and manage Istio yourself or use a one-click install feature of your Kubernetes or cloud provider. Another option is to turn to a provider for a fully managed service mesh based on Istio. Choose the way that works for you.
